# Maago

**에이전트가 웹 애플리케이션을 쓰고, 기계가 그 코드를 실행 전에 검증하는 Go 프레임워크.**
모델은 Django처럼 struct에 선언하고, SQL은 MyBatis처럼 파일에 손으로 쓴다.
